UNDER THE HOOD

The judge supplies the reward. The agent learns the actions. Tabular Q-learning updates from the judge’s outcome probabilities. JEV receives structured state, including computed route distances; the agent sees only position and key possession. This is a small, inspectable experiment—not a pixel-based or general-game benchmark.
